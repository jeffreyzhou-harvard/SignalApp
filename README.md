# Signal

Your followers' bios, posts, and engagement — embedded into constellations.
One launch, engagement-tuned for every niche.

Signal clusters your real X followers from persona embeddings, lets a voice
copilot turn a launch brief into tailored post + Grok Imagine creative per
niche, wind-tunnels variants on simulated agents, and ships the winner from
your own account.

- Frontend (Next.js): repo root — `npm install && npm run dev`
- Backend (ingest + embeddings + MCP): [backend/](backend/) — `uv run uvicorn app.main:app`
- Vision & architecture: [docs/](docs/) · Voice harness map: [AGENTS.md](AGENTS.md)
